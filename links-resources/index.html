Links & Resources

Projects and Data-sets:

My open-source projects, datasets and research material, grouped by topic. More on GitHub: github.com/kourgeorge

AI safety & LLM evaluation
  • prompt-sentinel
    A Python library that hides sensitive data before prompts are sent to outside LLMs.
    ★ 5Python[docs][PyPI]
  • AttaQ dataset
    A red-teaming dataset of 1,402 adversarial questions for testing whether LLMs give harmful answers.
  • ProvoQ dataset
    2,705 human-curated provocative questions for testing how LLMs handle stigma-related topics.
  • llmrace
    "Speedtest.net, but for LLMs": measures model speed from the terminal.
    TypeScript
  • vending-bench-arena
    A benchmark where an LLM agent runs a virtual vending-machine business.
    Python
AI agents & agent tools
  • symcc
    A Claude Code plugin that runs a team of coding agents from one chat.
    ★ 1TypeScript
  • agents-patterns-atlas
    An online book of design patterns for AI agents.
    ★ 1Python[site]
  • jarvis
    A personal-assistant agent built with LangChain, with email, calendar and other tools.
    ★ 3Python
  • ssh-docs
    Serves documentation over a read-only SSH server, so AI agents can browse it with shell commands.
    Python
Simulators & artificial life

  • plus-maze-simulator
